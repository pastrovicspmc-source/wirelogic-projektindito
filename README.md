# WireLogic Projektindító V0.2 – tesztverzió

Előzetes projektigények megadására szolgáló, magyar nyelvű adatlap.
A megadott válaszok nem helyettesítenek műszaki vagy biztonsági tervet.

## Használat

1. Nyisd meg a weboldalt, vagy töltsd le és nyisd meg az index.html fájlt.
2. Töltsd ki az ismert adatokat. Csak a projekt megnevezése kötelező.
3. A **JSON mentése** gombbal töltsd le a kitöltött adatokat.
4. A JSON-fájlt külön add át a projekt felelősének.

**A JSON letöltése nem jelenti az adatlap beküldését.**
A mezők mentés után megmaradnak, de az oldal bezárása vagy frissítése
elveszítheti a kitöltést. Nincs automatikus mentés vagy visszatöltés.

Az adatlap a böngészőben működik; nem küldi el a kitöltött válaszokat,
nem tárolja azokat központilag, nincs analitika vagy automatikus e-mail.
A weboldal megnyitásához internetkapcsolat szükséges; a letöltött HTML
önállóan, offline is használható. Edge és Chrome böngészőben tesztelt.

A visszajelzéseket e-mailben küldd annak, akitől a tesztoldal címét kaptad.
A kitöltött JSON személyes vagy üzleti adatot tartalmazhat; csak az érintett
projekt felelősének add át.

A JSON formátumazonosítója wirelogic-project-intake, verziója 2.
A WireLogicba történő automatikus import külön későbbi fejlesztés.
